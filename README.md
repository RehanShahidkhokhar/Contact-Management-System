Contact Management System
Overview
This is a simple contact management system implemented in C++ to manage personal or business contacts. The system allows users to add, search, update, and delete contact information efficiently.

Features
Add new contacts
Search by name or phone number
Update existing contacts
Delete contacts
View all contacts
Running the Program
1. Running the Program Without a Code Editor
Setup: Ensure you have a C++ compiler installed (e.g., GCC, Clang).

Compilation: Open a terminal and navigate to the project directory.

bash
Copy code
g++ -o contact_manager main.cpp
Execution: Run the compiled program.

bash
Copy code
./contact_manager
Usage: Follow the on-screen prompts to interact with the system (Add, Search, Update, Delete contacts).

2. Running the Program with a Code Editor
Setup: Open your preferred C++ code editor (e.g., Visual Studio Code, Eclipse, or any IDE supporting C++).

Loading the Code: Load the main.cpp file into the editor.

Compilation: Build the project within the IDE or terminal by running:

bash
Copy code
g++ -o contact_manager main.cpp
Execution: Execute the program by running:

bash
Copy code

Usage: Interact with the system through the provided user interface for managing contacts.

How It Works
Adding Contacts: You can add new contacts by entering their name, phone number, and email address.
Searching Contacts: Use the search functionality to find specific contacts by name or phone number.
Updating Contacts: Modify existing contact details as needed.
Deleting Contacts: Remove contacts from the system.
